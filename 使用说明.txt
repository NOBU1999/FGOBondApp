FGO牵绊推荐器 操作手册（Windows 便携版）
=========================================
适用版本：v0.1.10 及以上
程序性质：本地运行，不需要注册表、不需要安装，离线也能计算
免责声明：仅用于非商业的个人学习与游戏辅助用途；
          游戏素材、文本与角色数据版权归 TYPE-MOON / FGO Project 等相关权利方所有
数据来源：Atlas Academy API；部分中文译名参考 Chaldea 项目（非官方翻译）
开源许可：AGPL-3.0-only


────────────────────────────────────────
一、快速开始（3 分钟）
────────────────────────────────────────
1. 把整个文件夹解压到任意【可写】目录（建议英文路径，例如 D:\FGOBond），
   双击 FGO牵绊推荐器.exe 启动。首次启动会自动用 db\fgo_data.seed.db 生成运行库。
2. 顶部「服务器」选择 日服 / 简中服。
3. 点「Box管理」→ 逐个点选你持有的从者（或点「导入抓包数据」一次性导入）。
4. 右侧「队伍配置」设置 Cost上限 / 策略 / 计算质量。
5. 点 🚀 开始计算，等结果出来。想看某个方案为什么是这个收益，点结果卡上的「详情」。


────────────────────────────────────────
二、界面总览
────────────────────────────────────────
- 顶部工具栏：账号下拉框｜＋ 新建 / 管理｜Box管理｜排除管理｜自定义礼装｜更新数据
- 模式切换：普通战斗 / 戴冠战模式
- 服务器：日服 / 简中服
- 主区域：6 个槽位（5 个玩家位 + 1 个助战位），每槽 = 从者 + 礼装（戴冠战另有第二礼装位）
- 队伍配置：Cost上限、策略、计算质量、基础牵绊获取数值（指定从者最大化时还有目标选择）
- 结果区：方案列表、分页、详情、对比、复制验证串 / 反馈摘要
- 通用操作：弹窗右上角 ✕ 关闭；很多功能藏在【右键菜单】里（槽位、头像、结果卡）


────────────────────────────────────────
三、多账号（一个账号 = 一套 Box + 一套排除列表）
────────────────────────────────────────
用途：大号 / 小号 / 不同服务器的 Box 分开管理，互不影响。

- 切换账号：点顶部「账号」下拉框（括号里是该账号的从者数）
- ＋ 新建 / 管理（打开「账号管理」窗口）：
  · 新建账号：填名称（留空自动命名"账号 N"），可勾选
    「复制当前账号的 Box 与排除列表」——用大号 Box 建小号时最省事
  · 重命名：点账号行的「重命名」→ 改名 → 保存（Esc 取消）
  · 复制：以该账号为模板再建一个
  · 删除：删除该账号的 Box 与排除列表（不可恢复；至少保留 1 个账号）
- 切换账号后会重新载入该账号的 Box 与排除列表，并清空上一次的推荐结果（需重新计算）
- 所有账号共享：固定队伍预设、自定义礼装
- 「导入抓包数据」只会写进当前账号
- 从旧版本升级上来的数据，会自动成为「默认账号」


────────────────────────────────────────
四、服务器与数据
────────────────────────────────────────
- 日服 / 简中服：影响可选从者与灵衣、特性数据表、以及礼装在简中服的可用性
  （切到简中服后，简中服尚未实装的牵绊礼装不会进入自动搜索）
- 更新数据（顶部按钮 → 弹窗内）：
  · 检查并更新：有新版数据时才下载
  · 强制更新：忽略版本直接重新拉取
  · 过程显示各项进度，完成后无需重启
- 重置数据库（菜单「工具 → 重置数据库」，用于修数据）：
  · 会先清空本地【静态数据】（从者 / 礼装 / 特性 / 灵衣），再强制重建一次，
    比"强制更新"更彻底（能清掉上游已删除的旧条目）
  · 个人数据不受影响：账号 / Box / 排除列表 / 固定预设 / 自定义礼装都会保留
  · 重建前自动备份到 db\backup\pre-reset-时间.db；重建失败或读不到数据会自动回滚
- 数据来自 Atlas Academy；日常计算完全离线


────────────────────────────────────────
五、Box 管理（你持有哪些从者、什么状态）
────────────────────────────────────────
打开：顶部「Box管理」

1) 勾选持有
   · 点一下头像 = 标记持有 / 取消持有（头像会打勾）
2) 搜索与筛选
   · 关键字搜索；职阶、星级、持有状态、满绊状态筛选；排序方式与 ↓倒序/↑正序
3) 满绊与加成标记
   · 勾选后头像下方出现「绊」标记，点它 = 切换「满绊」（达到当前牵绊上限）
   · 右键头像 → 「⚙️ 从者设置」可精细设置：
     - 固定阶段 / 灵衣（不选则由引擎按特性礼装自动挑最优）
     - 当前牵绊等级、牵绊等级上限（满绊判定用，玛修上限特殊）
     - 满绊标记
     - 全队25%加成（只有 15 级以上的满绊生效）
     - 开关二（自身参与收益）
     - 个人加成(%)、玛修全队光环(%)
     - 从活动导入该从者加成
   · 右键头像 → 「🔍 从者属性」查看该阶段/灵衣的特性列表
     （红边 = 命中当前队伍特性礼装的条件）
4) 批量设置加成（Box管理 → 批量设置加成）
   · 勾选多个从者 → 填「个人加成(%)」→ 应用加成
   · 「导入（先清空原加成）」：按活动批量导入牵绊加成
   · 「恢复默认（全部0）」：清空全部个人加成
   · 全选 / 取消当前选择
5) 导入抓包数据（Box管理 → 导入抓包数据）
   · 支持 Chaldea 的抓包文件（.php / .txt / .json）
   · 会读取 userSvt + userSvtStorage（含第二保管室），只以「实际持有」为准，
     不会把图鉴里的从者误判为持有
   · 依据 friendshipRank / friendshipExceedCount 推断牵绊等级与上限，
     自动标好满绊与"参与全队25%加成"
   · 只写入当前账号，并覆盖当前账号原来的 Box
6) 恢复Box默认
   · 清空所有勾选、满绊标记、阶段、加成设置（会二次确认）


────────────────────────────────────────
六、排除管理（只影响自动计算，不改动 Box 数据）
────────────────────────────────────────
打开：顶部「排除管理」

- 两个标签页：「排除从者」「排除礼装」
- 支持搜索、职阶/星级/满绊筛选、排序（↓倒序 / ↑正序）、
  「全选当前列表」、「取消当前选择」
- 被排除的从者不会进入自动搜索；被排除的礼装不会被自由位选中
- 手动排除对助战位不生效（助战是"借别人的"）
- 简易排除（只看本次结果）：
  在推荐结果里右键某个从者 → 「🚫 简易排除」，立即从当前结果里过滤掉；
  结果区上方会出现被排除从者的标签，点标签即可取消


────────────────────────────────────────
七、自定义礼装
────────────────────────────────────────
打开：顶部「自定义礼装」

- ＋ 新建礼装：名称、类型（牵绊 / 其他）、Cost、星级、
  百分比加成(%)、固定数值加成、是否可重复装备、加成条件
- 加成条件：
  · 无条件：对全队生效
  · 按条件：一个「条件组」内是 AND（同时满足），多个条件组之间是 OR（满足任一即可）
  · 特性输入框可输入或从下拉里选择常见特性（例如 杀阶）
- 列表里可「编辑 / 停用 / 删除」；停用的礼装不参与自动计算
- 自定义礼装与内置礼装同等参与自动搜索与成本计算


────────────────────────────────────────
八、队伍配置
────────────────────────────────────────
- 选择从者 / 礼装：左键点槽位 → 弹出选择器
  选择器支持关键字、职阶、星级、「仅显示持有」、礼装类型（牵绊/其他）、排序
- 右键槽位菜单：
  · ⚙️ 从者设置 / 🔍 从者属性
  · 设为助战 / 取消助战
  · ✴️ 设为冠位从者位（戴冠战模式）
  · ✏️ 更换（更换从者或礼装）
  · 🗑️ 清空（从者+礼装 / 礼装 / 第二礼装）
- 拖拽整理：
  · 拖动从者头像到另一个槽 = 交换整个槽位（从者 + 阶段 + 礼装 + 冠位/助战标记）
  · 拖动礼装到另一个礼装格 = 交换礼装
- 工具按钮：清空队伍｜随机填充自由位｜保存队伍｜加载预设｜🚀 开始计算｜⏹ 终止计算
- 队伍配置面板：
  · Cost上限：50 ~ 200（只有从者与主礼装计入 Cost，冠位第二礼装位 Cost 为 0）
  · 策略：总牵绊最大化 / 指定从者最大化 / 均衡模式
  · 计算质量 / 等待时间：快速（约35秒）/ 平衡（约60秒）/ 高质量（约135秒）/ 极限精算（约300秒）
  · 基础牵绊获取数值（默认 0）：填 0 时结果只显示倍率；填实际基础值后显示预计牵绊数
  · 指定从者最大化：在搜索框里找并点选目标从者
- 固定队伍预设（保存在本地，所有账号共用）：
  · 保存队伍 → 输入名称 → 保存
  · 加载预设 → 加载 / 删除


────────────────────────────────────────
九、计算与结果
────────────────────────────────────────
1) 开始计算
   · 🚀 开始计算；计算中可随时 ⏹ 终止计算（结果区会出现 🔁 重新计算）
   · 时间是"上限"不是"必须等满"：通常远早于上限就出结果
   · 质量档位越高，搜索越充分，越慢
2) 结果卡片
   · 显示：排名、总倍率、成员、礼装、Cost
   · 按钮：「详情」展开/收起、「导出JSON」导出该方案
   · 结果区标题显示：候选队伍总数 / 当前显示数
3) 详情内容（可在显示设置里逐项开关）
   · 成员加成计算式、Cost 明细
   · 特性礼装的触发条件与命中成员
4) 右键结果卡
   · 从者：🚫 简易排除 / ℹ️ 查看属性
   · 礼装：ℹ️ 查看信息（加成数值、类型、触发条件）
5) 多选与对比
   · 先在「结果显示设置」里开启「方案对比模式」，结果卡上会出现「选择」勾选框
   · 勾选 2 个以上方案 → 「📊 对比已选（N）」并排比较；「清空选择」取消
6) 📋 复制验证串（左键复制 / 右键切换模式）
   · 复现模式（默认，串较短）：反馈问题时用，能让开发者复现同一结果
   · 完整模式（含全量静态数据）：不依赖本地数据也能复现
   · 注意：验证串可能包含你的 Box 信息，公开分享前请自行确认
7) 📝 复制反馈摘要（左键复制 / 右键切换模式）
   · 简短模式：只含勾选的方案
   · 完整模式：额外包含队伍配置、参与计算的 Box、礼装池


────────────────────────────────────────
十、结果显示设置
────────────────────────────────────────
入口：左上角菜单「设置 → 结果显示设置...」（快捷键 Ctrl+,）
设置会保存在本地，下次启动仍然生效。

- 计算完成后自动展开第 1 个方案详情
- 在结果区显示本次搜索统计（档位/耗时/处理组合数）
- 在详情里显示成员加成计算式
- 在详情里显示成员 Cost 明细
- 显示特性礼装的触发条件
- 显示特性礼装的命中成员
- 显示客户端版本 / 数据更新时间 / 数据区
- 在方案从者头像角标显示牵绊等级
- 隐藏空礼装槽
- 隐藏助战位
- 开启方案对比模式（结果卡出现勾选框）
- 每页显示数量：20 / 50 / 100
- 结果最多计算数量：100 / 300 / 1000（默认 1000；改小可以更快看到结果）

────────────────────────────────────────
十二、更新版本（个人数据不会丢）
────────────────────────────────────────
【重要】更新系统目前处于测试阶段
  · 更新器的安装 / 回滚流程仍在验证中，受杀毒软件、显卡驱动、系统环境影响可能失败
  · 第一次使用前，请先备份整个程序文件夹（至少备份 db 文件夹）
  · 更新过程本身不会碰 db 文件夹（账号 / Box / 排除 / 预设），
    但"先备份一份"永远是唯一万无一失的保险
  · 万一出问题的退路：
    ① 双击 updater.exe，选一个旧版本安装包回滚；
    ② 直接解压旧版本发布包覆盖程序文件（个人数据不会丢）

【推荐】工具 → 安装新包...
  1. 选择下载好的新版本安装包（zip 或 7z）
  2. 点确定后程序会关闭，更新器接管：
     · 显示包内版本、支持基于的版本区间、当前版本、安装包大小
     · 不在兼容区间内时只做警告，确认后仍可安装
  3. 自动完成安装并重新启动程序
  4. 确认框里可以选择是否保留安装包（用于一键回滚，会占用约一个安装包的空间）

【其他入口】
  · 双击程序目录里的 updater.exe → 选择安装包
  · 把 zip / 7z 直接拖到 updater.exe 上
  · 主程序打不开时也能用它更新或回滚

【回滚】
  工具 → 回滚到上一版... → 用保留下来的包重新安装一次；没有保留则让你手动选旧包

【手动更新（同样安全）】
  直接把新版本解压覆盖到原文件夹即可。
  发布包里只有静态数据 db\fgo_data.seed.db；你的个人数据在 db\fgo_data.db，
  该文件不在发布包内，覆盖不到。

【数据保护机制】
  · 安装只替换程序文件，个人数据文件会原样带进新版本
  · 更新前会在 db\backup 里留一份运行库快照（保留最近 5 份）
  · 整个过程用"先展开到新目录、再改名替换"，中途失败会回滚，原目录不受影响

【目录说明】
  · db\fgo_data.seed.db  静态数据（随版本更新，不要手动修改）
  · db\fgo_data.db       你的账号 / Box / 排除 / 预设 / 自定义礼装（个人数据，勿删）
  · db\backup\           自动备份的旧运行库、更新前快照、更新日志
  · db\updates\          保留下来的安装包（用于一键回滚）


────────────────────────────────────────
十三、数据备份与迁移
────────────────────────────────────────
- 全部个人数据都在 db\fgo_data.db（加上 db\backup\ 里的历史备份）
- 换电脑 / 换文件夹：把整个程序文件夹拷过去即可；只搬数据就拷 db\fgo_data.db
- 想从零开始：删掉 db\fgo_data.db 再启动（会用种子库生成全新运行库）
- 建议定期把 db 文件夹复制到别处（U 盘 / 网盘）作为保险


────────────────────────────────────────
十四、常见问题
────────────────────────────────────────
Q1. 提示"当前配置下无法组成任何队伍"
    原因通常是：Cost 上限太低、Box 勾选的从者太少、排除项太多，
    或固定位之间互相冲突。提高 Cost 上限 / 多勾几个从者后重算。

Q2. 计算很久没出结果
    · 降低「计算质量」档位（快速约 35 秒）
    · 缩小「结果最多计算数量」（显示设置里可改成 100 或 300）
    · 随时可以点 ⏹ 终止计算

Q3. 想要的从者搜不到
    · 检查服务器选择：简中服未实装的从者不会出现
    · 检查 Box 的筛选条件（职阶/星级/持有/满绊）
    · 图鉴号异常/未实装的角色会被过滤掉

Q4. 头像显示成名字首字
    · 该从者缺少头像图片文件（不影响计算）

Q5. 中文名看起来怪
    · 官方译名与 Chaldea 参考译名可能不同；可在「更新数据」后同步最新译名

Q6. 更新后要重新计算吗
    · 结果不会持久化，重开或切换账号后需要重新计算（配置会保留）

Q7. 验证串会泄露隐私吗
    · 复现模式与完整模式都可能包含你的 Box 内容，公开分享前请自行确认

Q8. 杀毒软件 / SmartScreen 提示
    · 便携版未做数字签名，Windows 或杀软可能提示；
      选择"更多信息 → 仍要运行"，或在杀软里把程序目录加入白名单

Q9. 能装在 C:\Program Files 吗
    · 不建议：更新时需要在程序目录改名，系统保护目录会失败。
      请放在用户可写目录（如 D:\FGOBond）；放在桌面也可以

Q10. 手机 / Android 能用吗
    · 目前只有 Windows 便携版

Q11. 界面偶发假死 / 卡住不动，但程序没崩
    · 这是 Electron（Chromium）在 Windows 上的已知问题类别，程序已内置两层缓解：
      · 关掉 Windows「窗口遮挡计算」，避免窗口被其他窗口挡住后不再刷新
      · 窗口失焦/被遮挡时不限制渲染
    · 如果仍然出现，程序会自动把诊断信息写到 db\backup\renderer-日期.log
      （记录了渲染进程无响应、GPU/子进程异常退出、GPU 特性状态），
      把这个文件反馈给作者即可定位
    · 临时规避：用「软件渲染」启动，命令行执行
        FGO牵绊推荐器.exe --disable-gpu
      或先设置环境变量 FGO_DISABLE_GPU=1 再启动。
      如果软件渲染下不再假死，基本可以确认是显卡驱动 / GPU 加速问题，
      可更新显卡驱动，或固定使用软件渲染启动
