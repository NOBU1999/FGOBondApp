FGO牵绊推荐器 操作手册
=========================================
适用版本：v0.1.10 及以上（**Windows 便携版 / 安卓版**；两版的按钮位置差异在第二、十章标注）
程序性质：本地运行，不需要注册表、不需要安装，离线也能计算
免责声明：仅用于非商业的个人学习与游戏辅助用途；
          游戏素材、文本与角色数据版权归 TYPE-MOON / FGO Project 等相关权利方所有
数据来源：Atlas Academy API；部分中文译名参考 Chaldea 项目（非官方翻译）
开源许可：AGPL-3.0-only


────────────────────────────────────────
一、快速开始（3 分钟）
────────────────────────────────────────
1. 把整个文件夹解压到任意【可写】目录（建议英文路径，例如 D:\FGOBond），
   双击 FGO牵绊推荐器.exe 启动。首次启动会自动用 db\fgo_data.seed.db 生成运行库。
2. 顶部「服务器」选择 日服 / 简中服。
3. 点「Box管理」→ 逐个点选你持有的从者（或点「导入抓包数据」一次性导入）。
4. 右侧「队伍配置」设置 Cost上限 / 策略 / 计算质量（「活动从者优先」也在这一栏）。
5. 点 🚀 开始计算，等结果出来。想看某个方案为什么是这个收益，点结果卡上的「详情」。


────────────────────────────────────────
二、界面总览
────────────────────────────────────────
- 顶部工具栏：
  · Windows：左侧「设置 ▾」下拉（计算设置 / 结果显示设置 / 诊断日志）｜账号下拉框｜＋ 新建 / 管理
             右侧 Box管理｜排除管理｜自定义礼装｜更新数据
  · 安卓：账号下拉框｜＋ 新建 / 管理｜Box管理｜排除管理｜自定义礼装｜设置｜使用说明（没有系统菜单与快捷键）
  · 左上角「FGO牵绊推荐器」这个**标题可以点**：打开「版本与更新信息」（检查有没有新版本，见第十一章）
- 使用说明：Windows 按 F1 或菜单「帮助 → 使用说明」；安卓点工具栏「使用说明」——都在应用内阅读
- 模式切换：普通战斗 / 戴冠战模式
- 服务器：日服 / 简中服
- 主区域：6 个槽位（5 个玩家位 + 1 个助战位），每槽 = 从者 + 礼装（戴冠战另有第二礼装位）
  · 右下角会有橙黄色提示：**自由位 ≥4 个**（也就是最多只固定了 1 位从者）时提醒"耗时更久、结果更易波动，
    建议开超级模式"；鼠标停在旁边的 ⓘ 上有说明。
    这一行位置是**固定预留**的 —— 提示出现或消失都不会挤动下面的面板
- 主区域下方：Cost 摘要（Cost / 固定 / 自由 / 助战）与操作按钮
  （清空队伍｜随机填充自由位｜保存队伍｜加载预设｜🚀 开始计算｜⏹ 终止计算；计算中还有进度条）
- 队伍配置（分三组）：
  · 基础：Cost上限、策略（指定从者最大化时还有目标选择）
  · 搜索强度：邻域优化、计算质量、结果最多计算数量、**活动从者优先**
    （勾上后，不足 +50% 的活动加成从者也优先纳入计算；+50% 及以上的本来就总是优先纳入）
  · 牵绊与排序：基础牵绊获取数值（填了之后可切换按倍率 / 按牵绊点数排）
  右上角还有 **🚀 超级模式**开关（愿意多等几分钟换更全的搜索，见第十章）
- 结果区：方案列表、分页、详情、对比、复制验证串 / 反馈摘要
- 通用操作：弹窗右上角 ✕ 关闭；很多功能藏在【右键菜单】里（槽位、头像、结果卡）


────────────────────────────────────────
三、多账号（一个账号 = 一套 Box + 一套排除列表）
────────────────────────────────────────
用途：大号 / 小号 / 不同服务器的 Box 分开管理，互不影响。

- 切换账号：点顶部「账号」下拉框（括号里是该账号的从者数）
- ＋ 新建 / 管理（打开「账号管理」窗口）：
  · 新建账号：填名称（留空自动命名"账号 N"），可勾选
    「复制当前账号的 Box 与排除列表」——用大号 Box 建小号时最省事
  · 重命名：点账号行的「重命名」→ 改名 → 保存（Esc 取消）
  · 复制：以该账号为模板再建一个
  · 删除：删除该账号的 Box 与排除列表（不可恢复；至少保留 1 个账号）
- 切换账号后会重新载入该账号的 Box 与排除列表，并清空上一次的推荐结果（需重新计算）
- 所有账号共享：固定队伍预设、自定义礼装
- 「导入抓包数据」只会写进当前账号
- 从旧版本升级上来的数据，会自动成为「默认账号」


────────────────────────────────────────
四、服务器与数据
────────────────────────────────────────
- 日服 / 简中服：影响可选从者与灵衣、特性数据表、以及礼装在简中服的可用性
  （切到简中服后，简中服尚未实装的牵绊礼装不会进入自动搜索）
- 更新数据（Windows：顶部「更新数据」按钮 → 弹窗里有**两个**按钮）：
  · 「检查刷新」：只比对远程有没有新数据（秒回、不下载）——先看值不值得更新
  · 「更新数据」：无条件重新下载并重建静态数据（不看版本号，慢一些）
  · 过程显示各项进度，完成后无需重启
  · 更新完会自动检查新从者的头像并补下载（只下载图片，不上传任何数据；
    没网或下载失败不影响使用，下次更新再补）
  · 安卓端没有这个入口：静态数据随 APK 一起发布，下载新 APK 覆盖安装即可
- 重置数据库（Windows：菜单「工具 → 重置数据库」，用于修数据）：
  · 会先清空本地【静态数据】（从者 / 礼装 / 特性 / 灵衣），再强制重建一次，
    比「更新数据」更彻底（能清掉上游已删除的旧条目）
  · 个人数据不受影响：账号 / Box / 排除列表 / 固定预设 / 自定义礼装都会保留
  · 重建前自动备份到 db\backup\pre-reset-时间.db；重建失败或读不到数据会自动回滚
  · 安卓端也没有这个入口（安卓没有系统菜单）
- 数据来自 Atlas Academy；日常计算完全离线


────────────────────────────────────────
五、Box 管理（你持有哪些从者、什么状态）
────────────────────────────────────────
打开：顶部「Box管理」

1) 勾选持有
   · 点一下头像 = 标记持有 / 取消持有（头像会打勾）
2) 搜索与筛选
   · 关键字搜索；职阶、星级、持有状态、满绊状态筛选；排序方式与 ↓倒序/↑正序
3) 满绊与加成标记
   · 勾选后头像下方出现「绊」标记，点它 = 切换「满绊」（达到当前牵绊上限）
   · **填了「当前牵绊等级 + 上限」的从者，三个标记会按规则自动判定**（不用手勾）：
     牵绊 **Lv ≥ 15** ⇒ 给全队 **+25%**（官方职阶技能「梦火的引导」，与是否满绊无关，
     上限开到 16 之后依然生效）；**没到上限** ⇒ 该从者自己的牵绊照常累加（15/16 这种就是）。
     想改回手勾，把等级填 0 即可。
   · 右键头像 → 「⚙️ 从者设置」可精细设置：
     - 固定阶段 / 灵衣（不选则由引擎按特性礼装自动挑最优）
     - 当前牵绊等级、牵绊等级上限（≥1 时上面那套自动判定生效，玛修上限特殊）
     - 满绊标记 / 全队25%加成 / 开关二（自身参与收益）—— 等级填了的时候是自动的，会置灰
     - 个人加成（%）、玛修全队光环（%）
     - 从活动导入该从者加成
   · 右键头像 → 「🔍 从者属性」查看该阶段/灵衣的特性列表
     （红边 = 命中当前队伍特性礼装的条件）
4) 批量设置加成（Box管理 → 批量设置加成）
   · 勾选多个从者 → 填「个人加成（%）」→ 应用加成
   · 「导入（先清空原加成）」：按活动批量导入牵绊加成
   · 「恢复默认（全部0）」：清空全部个人加成
   · 全选 / 取消当前选择
5) 导入抓包数据（Box管理 → 导入抓包数据）
   · 支持 Chaldea 的抓包文件（.php / .txt / .json）
   · 会读取 userSvt + userSvtStorage（含第二保管室），只以「实际持有」为准，
     不会把图鉴里的从者误判为持有
   · 依据 friendshipRank / friendshipExceedCount 推断牵绊等级与上限，
     自动标好满绊与"参与全队25%加成"
   · 只写入当前账号，并覆盖当前账号原来的 Box
6) 恢复Box默认
   · 清空所有勾选、满绊标记、阶段、加成设置（会二次确认）


────────────────────────────────────────
六、排除管理（三处「排除」的区别）
────────────────────────────────────────
界面上有三处能"排除"，作用范围与保存方式各不相同，别混用。
它们都**只影响计算，不改动你导入的 Box 数据**。
一句话记法：**① 是"我长期不用他"，② 是"这次先别用他"，③ 是"这张礼装别自动给我装"。**

【① 排除管理】顶部「排除管理」按钮 —— 长期的、按账号保存
   · 两个标签页：「排除从者」「排除礼装」；支持搜索、职阶/星级/满绊筛选、
     排序（↓倒序 / ↑正序）、「全选当前列表」、「取消当前选择」
   · 被排除的从者**不会进入自动搜索**（连候选池都不进）；被排除的礼装**不会被自由位选中**
   · 手动排除对助战位不生效（助战是"借别人的"）——从者、礼装都是
   · 保存：跟当前账号走（切账号各有各的名单），关掉程序也还在
   · 想恢复：再点一次取消勾选（或「取消当前选择」）

【② 简易排除】结果区里右键从者 —— 临时的、只看这一次
   · 在推荐结果里**右键某个从者** → 「🚫 简易排除」
   · 立刻把榜上**含该从者的队伍全部隐藏**；同时**下次重新计算**时他也会被排除
   · 结果区上方会出现一个「简易排除：」标签（后面列出被排掉的从者），**点标签就撤销**
   · 如果 Top 结果全含被简易排除的从者，会提示点「🔁 重新计算」搜替代队伍
   · 保存：**不保存**（只在本机内存里，切换账号或重启程序就没了）→ 适合"我先看看不要他会怎样"
   · 与 ① 的关系：简易排除名单会**临时叠加**到本次计算的排除上，但**不会写进**①的名单

【③ 礼装「不参与自动」】选择礼装时右键礼装 —— 长期的、全程序共用（不跟账号走）
   · 在**选择礼装**的列表里**右键礼装**即可切换；被设为不参与的会带一个「不参与」小标记
   · **默认不参与的只有 3 张**（"通用英灵"系列）：「通用英灵肖像」「通用英灵逢魔」「通用英灵极点」
     —— 需要它们参与就在列表里右键打开；其余牵绊礼装**默认参与**（含「通用5%」），右键可以关掉
   · 只影响"自动搜索时用哪些礼装"——**你手动放到槽位上的礼装照样计分**
   · 保存：全程序共用（所有账号一致），关掉程序也还在
   · 与 ①「排除礼装」的两点区别：
     a) **③ 连助战位也不会自动选它**；① 只管你自己的自由位，助战位照样会用（助战是"借别人的"）
     b) 保存范围不同：① 按账号，③ 全程序共用


────────────────────────────────────────
七、自定义礼装
────────────────────────────────────────
打开：顶部「自定义礼装」

- ＋ 新建礼装：名称、类型（牵绊 / 其他）、Cost、星级、
  百分比加成(%)、固定数值加成、是否可重复装备、加成条件
- 加成条件：
  · 无条件：对全队生效
  · 按条件：一个「条件组」内是 AND（同时满足），多个条件组之间是 OR（满足任一即可）
  · 特性输入框可输入或从下拉里选择常见特性（例如 杀阶）
- 列表里可「编辑 / 停用 / 删除」；停用的礼装不参与自动计算
- 自定义礼装与内置礼装同等参与自动搜索与成本计算


────────────────────────────────────────
八、队伍配置
────────────────────────────────────────
- 选择从者 / 礼装：左键点槽位 → 弹出选择器
  选择器支持关键字、职阶、星级、礼装类型（牵绊/其他）、排序（按序号 / 按牵绊数值）与 ↓倒序/↑正序
  （玩家位只列你 Box 里已勾选持有的从者；助战位可以选全部已收录角色）
- 右键槽位菜单：
  · ⚙️ 从者设置 / 🔍 从者属性
  · 设为助战 / 取消助战
  · ✴️ 设为冠位从者位（戴冠战模式）
  · ✏️ 更换（更换从者或礼装）
  · 🗑️ 清空（从者+礼装 / 礼装 / 第二礼装）
- 拖拽整理：
  · 拖动从者头像到另一个槽 = 交换整个槽位（从者 + 阶段 + 礼装 + 冠位/助战标记）
  · 拖动礼装到另一个礼装格 = 交换礼装
- 工具按钮（在队伍配置面板**上方**）：清空队伍｜随机填充自由位｜保存队伍｜加载预设｜🚀 开始计算｜⏹ 终止计算
- 队伍配置面板：
  · Cost上限：50 ~ 200（只有从者与主礼装计入 Cost，冠位第二礼装位 Cost 为 0）
  · 策略：总牵绊最大化 / 指定从者最大化 / 均衡模式
  · 计算质量 / 等待时间：快速（约35秒）/ 标准（约60秒）/ 平衡（默认，约90秒）/
    高质量（约135秒）/ 极限精算（约300秒）
    —— 档位只决定"引擎的搜索量 + 等待上限"，计划算完就返回（不会等满）；
       普通战斗 + 大 Box 时档位确有差别（越高越不容易被时间上限截断）；戴冠战/限定职阶通常没差别
  · 基础牵绊获取数值（默认 0）：填 0 时结果只显示倍率；填实际基础值后显示预计牵绊数
  · 指定从者最大化：在搜索框里找并点选目标从者
- 固定队伍预设（保存在本地，所有账号共用）：
  · 保存队伍 → 输入名称 → 保存。默认名 = 队伍里从者的名字（含助战，最多 6 个，用 _ 连接）；
    没选从者时给「新预设1 / 新预设2 …」
  · 保存时可勾「同时保存本次结果」（默认勾上）：结果与预设存在一起，列表里标「含结果」
  · 预设面板：一行一张卡（名字 + 时间 / Cost / 固定位标签），右边是「重命名」「加载」和「✕」删除
  · 「重命名」：点一下名字变成输入框，改完按回车（或点别处）保存，Esc 取消；只改名字，配置与存着的结果都不动
  · 加载带结果的预设会直接显示上次那份结果、**不重新计算**；想重算点「🚀 开始计算」，再存一次即更新
  · 加载**没有**结果的预设会把结果区清空（不会留着上一个预设的结果）


────────────────────────────────────────
九、计算与结果
────────────────────────────────────────
1) 开始计算
   · 🚀 开始计算；计算中可随时 ⏹ 终止计算（结果区会出现 🔁 重新计算）
   · 时间是"上限"不是"必须等满"：通常远早于上限就出结果
   · 质量档位越高，搜索越充分，越慢；想更彻底就用「超级模式」（见第十章）
2) 结果卡片
   · 显示：排名、总倍率、成员、礼装、Cost
   · 按钮：「详情」展开/收起、「导出JSON」导出该方案
   · 结果区标题显示：候选队伍总数 / 当前显示数
3) 同分可替换阵容（卡片右侧那个"同分 N 支"按钮）
   · 分数**完全相同**的阵容会被合并成一行；点这个按钮能看这一组里的每一支
   · 点其中一支 → 它就成为本行显示的阵容（名次不变，礼装与站位不动，只换从者）
   · 前后排算区别（前排 +20% 是真区别），但"只是谁站哪个位置"的重复会被折叠掉
   · 勾选方案后复制「反馈摘要 / 验证串」时，整组会一起带走，不会只留一支
4) 「本次搜索」那行（结果上方；可在显示设置里关掉）
   · 形如：🔍 本次搜索：平衡（默认，约 90 秒上限）· 用时 42s · 候选 23 人 · 已按分数从高到低核对 1,508 支队伍
   · 引擎**先把最可能进前排的队伍算完**，分数上限低于当前榜尾的组合会自动跳过
     ⇒ 所以排名靠前的部分是完整的；鼠标停在末尾的 ⓘ 上能看到完整说明
   · 想搜更大的范围，用「超级模式」（候选范围与组合上限一起放大）
5) 详情内容（可在显示设置里逐项开关）
   · 成员加成计算式、Cost 明细
   · 特性礼装的触发条件与命中成员
6) 右键结果卡
   · 从者：🚫 简易排除 / ℹ️ 查看属性
   · 礼装：ℹ️ 查看信息（加成数值、类型、触发条件）
7) 多选与对比
   · 先在「结果显示设置」里开启「方案对比模式」，结果卡上会出现「选择」勾选框
   · 勾选 2 个以上方案 → 「📊 对比已选（N）」并排比较；「清空选择」取消
8) 📋 复制验证串（左键复制 / 右键切换模式）
   · 复现模式（默认，串较短）：反馈问题时用，能让开发者复现同一结果
   · 完整模式（含全量静态数据）：不依赖本地数据也能复现
   · 注意：验证串可能包含你的 Box 信息，公开分享前请自行确认
9) 📝 复制反馈摘要（左键复制 / 右键切换模式）
   · 简短模式：只含勾选的方案
   · 完整模式：额外包含队伍配置、参与计算的 Box、礼装池


────────────────────────────────────────
十、设置（计算设置 / 结果显示设置）
────────────────────────────────────────
入口：Windows —— 左上角「设置 ▾」，里面分三块：计算设置 / 结果显示设置 / 诊断日志；
      安卓 —— 工具栏右侧「设置」按钮（安卓没有系统菜单，所以用按钮，三块一次性列出）。
快捷键 Ctrl+, 直接打开「结果显示设置」。设置会保存在本地，下次启动仍然生效。

【计算设置】

· 结果完整度：更全（默认） / 更快
  默认的「更全」会多跑一趟"按礼装批次挑人"的搜索：专门捞那种"几个人一起吃同一批礼装"的队伍
  —— 这类队按单人评分排不进候选池，很容易被漏掉。它不会改变第 1 名，只是让后面的推荐更完整。
  代价是大约多花 15% 时间；嫌慢可以切成「更快」（常规最优解照样都在）。

· 把 Box 里全部从者视为「非满绊」
  打开后所有人都按"还能继续涨"算（自身收益不再记 0），用来估算梦火喂给谁最划算；
  牵绊 Lv.15 以上给全队的 25% 照常计算，不受影响。

· 计算质量：快速 35 秒 / 标准 60 秒 / 平衡 90 秒 / 高质量 135 秒 / 极限精算 300 秒
  （档位越高，搜得越多、越可能找到更好的队；等待时间也越长）

· 邻域优化：关闭 / 标准 / 深入（算完后把靠前的队伍互相"换人"再算一遍，捞"混血"更优解）

· 超级模式（「队伍配置」面板右上角的开关，默认关闭）：不设时间上限，按最大范围搜索
  开启后「结果完整度 / 计算质量 / 邻域优化」交给它接管（固定按最大范围走），这三项会置灰；
  界面会换成红色主题，进度那里会显示"已评 X 支 / 已用 Y 秒"。
  覆盖倍数：×2.5（推荐）/ ×5 / ×10 —— 越大越可能找到更好的队伍，也越慢
  （普通请求通常几秒到 1 分钟；超级模式常见 1~3 分钟，×10 可能到 7 分钟以上）。
  中途想停就点「停止（保留已算结果）」：已经算出来的结果会保留并显示，不会白算一场。
  ⚠️ 它只决定"搜得多不多"，不改变评分口径；关掉开关就恢复用上面那三项设置。
  实测收益集中在"自由位多、候选空间大"的场景（固定位已经定好的场景基本不变）。

【结果显示设置】

- 计算完成后自动展开第 1 个方案详情
- 在结果区显示本次搜索统计（档位/耗时/处理组合数）
- 在详情里显示成员加成计算式
- 在详情里显示成员 Cost 明细
- 显示特性礼装的触发条件
- 显示特性礼装的命中成员
- 显示客户端版本 / 数据更新时间 / 数据区
- 在方案从者头像角标显示牵绊等级
- 隐藏空礼装槽
- 隐藏助战位
- 开启方案对比模式（结果卡出现勾选框）
- 每页显示数量：20 / 50 / 100
- 结果最多计算数量：20 / 50 / 100 / 200 / 500 / 1000（默认 200）
  · 它决定"显示多少条"，也会影响等待时间（条数越多，引擎越晚开始丢掉没希望的队伍 → 越慢）
  · **它不影响算出来的最高分**：20 / 100 / 200 / 1000 四个档位算出来的第 1 名是一样的

【诊断日志】（仅 Windows）

- 程序出错时这里会有记录（只在本机，不会上传）；可以「读取 / 复制全部 / 清空」，
  反馈问题时把复制的内容发来即可。


────────────────────────────────────────
十一、更新版本（个人数据不会丢）
────────────────────────────────────────
【怎么更新】解压新版本，覆盖到原来那个程序文件夹 —— 就这一步。
  · 发布包里只有静态数据 db\fgo_data.seed.db；你的个人数据在 db\fgo_data.db，
    这个文件不在发布包内，**覆盖不到**（账号 / Box / 排除 / 固定预设 / 自定义礼装都保留）
  · 覆盖前建议先把整个程序文件夹复制一份留底（至少备份 db 文件夹）——这是唯一万无一失的保险
  · db\backup\ 里本来就存着自动备份的旧运行库，出问题可以直接换回去

【想确认有没有新版本】
  · 点左上角「FGO牵绊推荐器」标题 →「版本与更新信息」；
    或菜单「帮助 → 关于」→ 点「检查软件更新」
  · 查到新版本会给一个「📣 关注动态及更新信息」按钮：用系统浏览器打开作者的 B 站动态页，
    新版本与更新说明都发在那里
  · 这一步**只查版本号**，不会下载、不会改动程序文件

【数据保护机制】
  · 更新只替换程序文件，个人数据文件（db\fgo_data.db）不在发布包里，覆盖不到
  · db\backup\ 保留最近若干份运行库快照，可随时手动换回
  · 数据库结构有变化时，新版会在首次运行时自动升级表结构（个人数据保留）

【目录说明】
  · db\fgo_data.seed.db  静态数据（随版本更新，不要手动修改）
  · db\fgo_data.db       你的账号 / Box / 排除 / 预设 / 自定义礼装（个人数据，勿删）
  · db\backup\           自动备份的旧运行库、更新前的快照、更新日志

十二、数据备份与迁移
────────────────────────────────────────
- 全部个人数据都在 db\fgo_data.db（加上 db\backup\ 里的历史备份）

────────────────────────────────────────
十三、常见问题
────────────────────────────────────────
Q1. 提示"当前配置下无法组成任何队伍"
    原因通常是：Cost 上限太低、Box 勾选的从者太少、排除项太多，
    或固定位之间互相冲突。提高 Cost 上限 / 多勾几个从者后重算。

Q2. 计算很久没出结果
    · 降低「计算质量」档位（快速约 35 秒、标准约 60 秒）
    · 缩小「结果最多计算数量」（显示设置里可改成 100 或 300）
    · 随时可以点 ⏹ 终止计算

Q2b. 结果区出现"本次搜索被时间上限截断"
    · 意思是：引擎还没按计划算完就被等待上限叫停了 —— 这条结果可能不是最优
    · 换更高的「计算质量」档位再算一次通常能更准（计划跑完就返回，不一定真的等满）
    · 或者缩小「结果最多计算数量」也是让它更快算完的办法

Q3. 想要的从者搜不到
    · 检查服务器选择：简中服未实装的从者不会出现
    · 检查 Box 的筛选条件（职阶/星级/持有/满绊）
    · 图鉴号异常/未实装的角色会被过滤掉

Q4. 头像显示成名字首字
    · 该从者缺少头像图片文件（不影响计算）
    · 程序会在「更新数据」时自动尝试补下载；补不到就保持现状（下次更新再试）

Q5. 中文名看起来怪
    · 官方译名与 Chaldea 参考译名可能不同；可在「更新数据」后同步最新译名

Q6. 更新后要重新计算吗
    · 结果不会持久化，重开或切换账号后需要重新计算（配置会保留）

Q7. 验证串会泄露隐私吗
    · 复现模式与完整模式都可能包含你的 Box 内容，公开分享前请自行确认

Q8. 杀毒软件 / SmartScreen 提示
    · 便携版未做数字签名，Windows 或杀软可能提示；
      选择"更多信息 → 仍要运行"，或在杀软里把程序目录加入白名单

Q9. 能装在 C:\Program Files 吗
    · 不建议：更新时需要在程序目录改名，系统保护目录会失败。
      请放在用户可写目录（如 D:\FGOBond）；放在桌面也可以

Q10. 手机 / Android 能用吗
    · 有安卓版（APK，从 GitHub Releases 下载）：算法、Box、排除、结果等功能与 Windows 一致
    · 升级：下载新 APK 直接覆盖安装即可（账号 / Box / 队伍都在，不会丢）；卸载会清数据
    · 差异：安卓没有系统菜单与 F1 快捷键 —— 设置、使用说明都放在工具栏按钮里；
      本手册里凡是提到「程序目录」「菜单栏」的地方，安卓端都不适用
    · 目前没有 iOS / macOS 版

Q11. 界面偶发假死 / 卡住不动，但程序没崩
    · 这是 Electron（Chromium）在 Windows 上的已知问题类别，程序已内置两层缓解：
      · 关掉 Windows「窗口遮挡计算」，避免窗口被其他窗口挡住后不再刷新
      · 窗口失焦/被遮挡时不限制渲染
    · 如果仍然出现，程序会自动把诊断信息写到 db\backup\renderer-日期.log
      （记录了渲染进程无响应、GPU/子进程异常退出、GPU 特性状态、以及计算/更新时的报错），
      把这个文件反馈给作者即可定位
    · 临时规避：用「软件渲染」启动，命令行执行
        FGO牵绊推荐器.exe --disable-gpu
      或先设置环境变量 FGO_DISABLE_GPU=1 再启动。
      如果软件渲染下不再假死，基本可以确认是显卡驱动 / GPU 加速问题，
      可更新显卡驱动，或固定使用软件渲染启动
