# shared/engine/ —— 引擎调用接口（只定接口，不做实现）

> 阶段 3–4 启用（目前是占位目录，**没有任何代码被调用**）。

## 放什么

界面与「计算引擎」之间的**唯一入口**，三种实现在背后互换：

| 实现 | 用于 | 现状 |
|---|---|---|
| 子进程 | Windows 便携版 | ✅ 已有（`main/python-process.js`，Electron 专属，将来挪到平台层） |
| Worker + WASM | 网页 / 安卓 | ⛔ 阶段 4 |
| 原生宿主（可选） | 安卓加速 | ⛔ 阶段 7（仅在 WASM 太慢时） |

接口形状（草案）：

```js
// 所有实现都必须满足这个形状
engine.calculate(request)   // → Promise<结果 JSON>（与 contracts/engine-protocol.md 完全一致）
engine.cancel()             // 停止当前计算
engine.updateData({force})  // 仅桌面实现支持；其他实现抛出"不支持"
engine.onProgress(cb)       // 订阅进度，返回取消订阅函数
```

## 硬性要求

1. **请求 / 结果 JSON 与桌面版逐字段一致**（`contracts/engine-protocol.md`），否则三平台结果不可比。
2. 进度是**单向通知**，不许用它回传业务数据。
3. 取消后必须能再次调用（不许留下"引擎占用中"的死状态）。
4. 同一请求在同一数据版本下应当**结果可比**；受 `timeoutMs` 墙钟影响时，
   至少保证"同一机器、同一负载下可复现"（阶段 3 要写清这个语义）。
